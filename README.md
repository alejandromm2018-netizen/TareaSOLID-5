# TareaSOLID-5
el principio de segregacion de interfaces dice que cada clase no debe esta obligada a implementar metodos que no ocupe, por ejemplo en este codigo tenemos una clase padre y sus clases hijas, digital y fisico que cada una de ellas esta emplementando diferentes funciones que cada una de ellas ocupe por ejemplo no se va a utilizar la funcion de envio para el producto de digital ya que este no lo ocupa, este ocupa otra funcion de expirar que esta misma pues no la ocupa el producto de tipo fisico porque no le es necesario a esto se refiere el principio de segregacion de interfaces
